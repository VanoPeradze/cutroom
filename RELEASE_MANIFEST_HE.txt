CUTROOM AI Director 5.6.1 — Release Manifest
================================================

מטרה: גרסת פיתוח מקומית מהודקת של CUTROOM, עם תהליך Director, שני מקורות, עריכה ידנית, ביטול וייצוא אמין.

עיקרי ההידוק:
- חומר הגלם נשמר בטרנזקציה ונבדק לפני שהוא מחליף מקור קיים.
- העלאה, הכנת מקור, Director, התקנת מודל וייצוא ניתנים לביטול בטוח.
- העלאות A ו־B עצמאיות ויכולות לרוץ במקביל, עם התקדמות וביטול נפרדים לכל מקור.
- Source Mixer זמין לפני ה־Director וב־Studio לשליטה בתפקידי מסך/מצלמה, אודיו, סדר עליון/שמאל, פריסה וסנכרון.
- במקור יחיד אפשר לסמן ידנית Facecam שמוטמע בתוך הווידאו; הסימון מחליף בבטחה זיהוי Vision שלא הצליח.
- שמירות משתמש מוגנות מפני התנגשויות revision ותהליכים ישנים אינם דורסים פרויקט חדש יותר.
- Startup, שחזור עבודות ו־API errors מטופלים ללא Stack Trace צפוי בממשק.
- סביבת הריצה נבדקת בפועל לפני הפעלת השרת.

Regression:
- כל מערך בדיקות ה־Core, API והרגרסיה חייב לעבור דרך scripts/validate_release.py.
- Story/Short/YouTube/Reel/Captions/Two-source וייצוא FFmpeg נבדקים ב־smoke tests אמיתיים.
- Server/Browser smoke רצים על פורט loopback פנוי ובסביבת Python המקומית של CUTROOM.
