# Editing together or independently

The timeline is your edited video, not the original recording's clock. Each clip also has a **Source in** position inside its recording. Original media is never overwritten.

## Start here

1. Click the ruler to seek. Space plays or pauses without changing the editing tool or preview mode.
   Zoom in/out centers on the playhead, clamped at timeline boundaries. Fit still shows everything; Zoom to selection still targets the selected range.
2. Choose **Range**, drag over an unwanted section, then **Remove from video**.
3. Choose **Select / Move** to drag one cut. **Cut** clicks split at one point; dragging with Cut also moves a clip, without switching tools.
4. **Undo** reverses manual edits. Changes save automatically.
5. Open **Output** for aspect ratio, resolution, export quality and 24/25/30/50/60 FPS.

To move just part of a clip, select it with **Range**, switch to **Select / Move**, and drag inside the selection. Only that range moves, not its enclosing recording. This works in Together, A only and B only. Clicking outside the range picks a different individual cut.

## Read-only original source navigation

`librarySourceMatch` maps an imported video's active half-open edit interval to `(video_source_start ?? source_start ?? 0) + (edit_time - start) * speed`. This is the independent picture clock, never the normal-speed embedded-audio clock. It rejects unavailable/non-video targets, invalid timing, times outside the occurrence and source exhaustion; it never falls back to A/B or silently clamps a held-frame location. Disabled/covered occurrences are allowed because this is original-source inspection, not a claim about the visible composite.

The inspector command preserves the edit cursor. Select/Move timeline double-click first validates then seeks the clicked edit time. Both reuse native source review, pause playback and seek once after matching metadata. Pending saves/gestures, unsaved captions or Full source mode block without flushing or submitting edits. A project/revision/occurrence/source identity pins delayed metadata and later submit actions. Existing In/Out values and browser-saved marks are unchanged; only explicit Save marks persists them. Original source sound is normal speed and is not the edited mix. Browser seeking remains approximate; no frame-accurate match or rendered-effect reproduction is promised.

## Choose the editing scope

| Mode | Remove | Move / duplicate |
| --- | --- | --- |
| Together (A+B), or Whole video with one source | Timeline Range/Cut out removes that time from both sources, layout and supported added media/text; closes the gap. | Closes the origin and inserts the selected cut with its paired source and layout; destination footage shifts without being overwritten. Duplicate inserts a copy. |
| A only / B only | Removes only that source and leaves a gap. | Closes the origin and inserts on that track only; the other stays still. |

**Selected-layer Split** is separate from Together source splitting. The main Split button, eligible profile shortcut, media inspector and Blade use the actual selected imported-media/custom-text occurrence. They preserve timeline duration, other occurrences and A/B protection, select the right piece and use shared Undo/Redo. Source A/B locks do not lock independent occurrences. A stale layer selection never redirects Split to underlying footage. Native layer split times align to output frames; each piece must be at least 0.08 seconds. Pan/zoom animation and fade-interior cuts are explicitly blocked until their retained phase can be represented correctly. Automatic transcript captions are not split by this tool.

**Selected-layer Trim / extend:** the native inspector edge buttons, active-profile trim shortcuts and imported-media/custom-text edge gestures share `media_trim` / `text_trim` actions (`clip_id`, `edge: start|end`, `time`). They edit one occurrence in place, preserve its ID and opposite endpoint, leave sequence duration and every other layer unchanged, and use shared Undo/Redo. Head edits advance normal audio and independent picture clocks; static unfaded edges may extend within edit/source bounds. A/B locks do not lock independent layers. A stale layer or automatic-caption selection never falls through to source trimming. Native gestures frame-align only the moved edge, preview the canonical guarded patch, and cancel without writes on Escape. Minimum retained duration is 0.08 seconds; custom text still obeys the 16-simultaneous limit.

Resizing visual pan/zoom, cutting inside either fade, extending a faded edge, negative source/picture time and source overflow reject atomically. Removed-side fades clear only once the retained edge reaches the flat part; the opposite outer fade and retained content stay unchanged. No-op edges consume no history. Source Q/W semantics and whole-occurrence moves remain unchanged. Existing numeric Start/End fields remain explicit `media_update` / `text_update` timing edits, not the new retained-content trim action; Media Source in now uses guarded Slip. Pending geometry/project changes and revision conflicts cancel stale native trim commands instead of replaying them against a newer clip.

**Imported-media Slip:** `media_slip` (`clip_id`, absolute normal-clock `source_start`) changes content inside one fixed video/audio occurrence. The picture in-point advances by source delta times picture speed, retaining any independent offset; no clock is clamped. Timeline endpoints, duration, occurrence ID, effects/framing, both fades, motion phase and every other layer stay unchanged. Faded/animated video is supported because its phase does not restart. Images, custom text, automatic captions and source A/B are explicitly unsupported. Source bounds reject the full operation. Legacy `media_update` Source in changes also reject negative picture time rather than silently clamping it.

The explicit Slip tool previews the canonical source patch, frame-aligns the signed delta only, saves once on release and cancels on Escape. Right means later source content; left means earlier. The Media inspector Source in field and Earlier/Later 1f buttons share the same action, project/geometry/revision guards and Undo. No new keyboard binding or Alt behavior. Existing numeric Start/End edits and whole-clip moves retain their previous semantics.

**Selected-layer fixed-duration Move:** `media_move` / `text_move` require `clip_id` and explicit destination `start`. The original occurrence identity, complete length, source/picture clocks, picture speed, audio/fade envelope, framing/motion and text/template styling are retained. No ripple, sequence extension, truncation, extra occurrence or asset mutation. Motion/fades are safe because their complete local phase moves with the occurrence. Whole-clip bounds, ready media, valid text overlap and shared pending/identity/revision checks reject atomically; a no-op consumes no history or redo. Movement remains available at occurrence capacity because no new row is created.

Native inspector **Visual stacking** exposes `media_reorder` with `position: backward | forward | back | front` for imported video/image occurrences. The operation permutes only existing visual slots in `manual.media_clips`; audio-only rows retain their exact slots and every occurrence retains its ID, timing, source clocks, fades, motion and other fields. This global order includes non-overlapping occurrences and is not persistent track assignment. All existing timeline assets must be ready/known, and the full ordered media identity is pinned across pending saves; a conflict loads the latest state without replaying a relative reorder. Boundary no-ops retain redo. The selected ID and playhead survive the shared Undo-capable transaction. Preview and export use the same saved order. Custom text and captions remain a separate upper layer; preview custom text now stays above all 200 supported media occurrences, matching export. No text/source/audio stacking API or timeline tool is implied.

**Direct viewer frame editing:** imported video/image occurrences use `media_transform {clip_id,x,y,w,h}` for one atomic geometry-only change. All four normalized coordinates are required and rounded to the existing nine-decimal media domain; x/y are 0..1, w/h .01..1, and the box must fit the canvas. Unknown fields, unavailable/nonvisual targets and invalid media are rejected. Validation does not rewrite unrelated source clocks, sound, fades, motion, metadata or timing. Equal geometry retains redo. Existing A/B locks do not lock independent pictures.

The native **Position & size → Edit frame in viewer** mode requires the selected enabled ready picture to be active at the paused edit cursor. Eight handles resize the outer frame with independent axes; dragging its body moves it. Fit/Fill, pan/zoom and chroma remain inside that frame, and stacking is unchanged. Fractional percentage controls remain the numeric/keyboard alternative with explicit 1% scrub/arrow steps. Preview uses a separate transient override, never the pending numeric-save map. It does not write the project before release. Escape, selection/project/cursor/output/viewport changes, invalid context or a new pending edit cancel a gesture and restore the saved picture; each valid release dispatches once. Saved project/clip/asset/output identity and revision are rechecked before commit, without stale conflict retries. Undo/Redo/reopen preserve the result and same selected occurrence. This adds no global tool, new timeline gesture, source transform, text transform, rotation, perspective or automatic aspect lock.

**Non-destructive occurrence availability:** `media_set_enabled` / `text_set_enabled` accept the selected `clip_id` and a strict boolean `enabled`. Absent means enabled for existing projects; native disabling stores `false`, and re-enabling removes that optional field. The transaction changes only that occurrence's flag, keeps the same ID/playhead and saved content, uses revision checks without stale retries, and is one Undo step. Repeated valid saved-state requests are no-ops. Disabling unavailable imported media is allowed so it can be bypassed without deleting its metadata; re-enabling requires the normal ready-asset and clip validation. Disabled rows remain editable and are included in capacity, overlap, gap-occupation and mixed-edit safety rules; Split/Duplicate inherit the state.


Preview releases disabled media players and their sound/chroma resources, excludes them from audible groups, and filters disabled custom text. Export omits those media inputs, used-only chroma targets, custom text burn-in and custom-caption SRT lines; source A/B and automatic transcript captions retain their own settings. Retained data is not removed from the project, timeline or searchable Index. An edit with no A/B clips but retained disabled layers is not an empty editor: playback/export remain available and show lower content or black where no picture contributes. This is not a track mute, audio-only mute, source disable or AI-caption visibility feature.

Native inspector **Timeline placement** offers Move to playhead (output-frame-aligned destination) and +/-1f (relative to the existing fractional start, at output FPS). Existing body dragging uses the same canonical start/end preview and awaited commit, retaining magnets, Alt bypass and boundary clamp. Blocked previews restore saved geometry; Escape/pointer cancellation or changed pointer scale do not save. The same ID remains selected, playhead stays fixed, Undo/Redo/reopen preserve the result. Source A/B movement, automatic-caption timing, edge Trim, Slip and numeric Start/End remain their distinct operations. No new profile shortcut or timeline tool.

The four media/text Start/End fields now use valid fractional numeric input plus explicit 0.01-second scrub/ArrowUp/Down stepping. These opted-in controls preserve their fractional anchor; their native one-second fallback spinners are hidden. Other numeric controls, Source in and default numeric-scrub semantics are unchanged. This fixes a browser step-mismatch found after a real frame nudge without converting numeric timing edits into Move.

**Selected-layer Duplicate at playhead:** main Clip tools and the media/custom-text inspectors copy the actual selected occurrence, then select the new ID. `media_duplicate` and `text_duplicate` accept `clip_id` and destination `start`; their API default remains the original position when `start` is omitted. Native UI always sends the output-frame-aligned edit cursor, including Full source audition's mapped cursor. The complete occurrence length, source/picture clocks and speed, fades, motion phase, framing and text/template fields are retained. Original occurrences, assets, A/B footage and sequence duration stay fixed; there is no ripple, overwrite, truncation, extension or source-file copy. Source A/B locks do not lock independent layers.

Whole-copy bounds, ready assets, the 200-media / 2,000-text capacities and 16 simultaneous custom-text limit reject before history changes. Pending geometry/asset/project changes or revision conflicts cancel stale requests rather than replay them; readiness follows seek/playback and existing pending-save gates. One shared Undo removes the copy, Redo and reopen retain it. Automatic transcript captions and stale layer selections never fall through to source duplication. Without independent layer selection, existing A/B Duplicate remains unchanged. No new gesture or keyboard binding is added.

**Timeline Together Cut out:** crossing imported video, audio, still images and custom text retain their left/right pieces with exact source clocks and styling; wholly selected occurrences leave the timeline, later occurrences shift left. The first retained piece keeps its identity. Original files and media-pool assets are never deleted. Review **Cut out preview** in timeline navigation for the duration change and removed/trimmed/split/shifted counts. One Undo restores all layers; Redo and saved reopen preserve the result. The whole edit may be emptied and populated again.

Partial pan/zoom animation, a newly cut boundary inside an audio fade, a retained media/text piece under 0.08 seconds, capacity limits, affected source locks, timed audio plans, active caption alternatives or ambiguous/overlapping reviewed automatic captions block the complete operation. Ordinary automatic captions follow retained source words. A/B-only removal and selected-media/text Delete retain their independent behavior. This specific command does not change Source Review removal, edge trimming, source reorder/insert/overwrite semantics.

Together is the default. Switching the mode preserves your selection. Clicking a lane never silently changes the mode. Together sections are divided at every A/B clip boundary; a Blade split can align both sources at the same time.

Dragging or **Move to start** now uses ripple insertion: the origin closes, and destination footage shifts without being overwritten. Drops beyond the end append without adding black time. The destination is a final edit position, after closing the origin. Existing intentional gaps remain until explicitly closed. **Undo** restores the complete move. Legacy API insert and overwrite modes remain supported.

In **Select / Move**, select a clip, then drag a white edge to shorten it or reveal more original footage into a gap. Extension stops at the media boundary or the next clip: it does not stretch/freeze frames or overwrite neighbors. Together shortening removes time from both tracks and their layout; source-only shortening leaves the other source untouched. Crop settings remain attached to clips. Zoom in to access handles on tiny clips.

**Close gaps** appears when the selected scope has empty time. **Together** removes only intervals empty across A/B, added video/audio/images and custom text/captions. Later clips on all those layers move left by the same removed time, keeping their relative alignment, source offsets, fades and styling. A music bed, title or other clip spanning an interval keeps that interval occupied, even when muted. A/B-only closes gaps on that source without moving the other source or added layers; an edit that would strand another layer beyond the new end is rejected. A protected source that would move blocks the whole operation. One **Undo** restores all affected layers, and **Redo** reapplies them. Original recordings and transcripts remain untouched. Close gaps, imported-video Insert and timeline Together Cut out each explicitly handle supported added layers; source reordering and other source-only commands keep their separate behavior. Active saved caption alternatives, independently retimed transcript captions and caption edits with uncertain ownership or source spans that would merge block Together gap closure rather than silently reverting the reviewed captions. Ordinary source-linked wording corrections and custom text/caption layers are supported. No-op closures remain available.

## More editing tools

### Frame each cut separately

Select a clip (or a range), open **Layout → Clip framing**, and choose source A or B. Horizontal focus, vertical focus and zoom save only to that section on that source, with Undo. Without a selection, the controls target the clip at the playhead; the displayed time range identifies the scope. Full source mode disables per-cut framing.

Framing follows clips through moves, copies and splits and is applied in both preview and export. An explicit clip crop fills that source's panel, even if the global layout uses Fit. Other clips keep their existing framing. For a camera embedded in one recording, these controls move the screen within the bottom panel without changing the camera window; zoom is unavailable for that layout.

**More tools** opens the inspector, without displacing the timeline.

- **Range…** accepts exact edit times as seconds or mm:ss.mmm.
- **Original footage** opens a large source player and the complete original timeline. Green sections are in the current edit; red sections are removed. Click a section or drag any range, preview it, then **Restore to edit** or **Remove from edit**. Previous/Next removed and zoom help review long recordings. Source and edited playback stay separate.
- Restore inserts only missing portions of the selected recording, near the next source neighbor (or after the preceding one). Existing clips keep their relative order even if you rearranged the story. Together restores the original synchronized A/B mapping and layout; source-only restores just that track, filling a corresponding gap when possible. Remove affects all uses of the selected interval, including copies; Together closes the gap, source-only leaves it. Each action is one Undo step. Original media and transcripts are not rewritten.
- **Place selected footage...** carries the reviewed original range and chosen scope into the placement form. Choose Insert or Overwrite and review the destination before applying; opening or cancelling the form does not change the edit.
- **Duplicate clip** copies the selected section. In Together it includes both tracks and layouts.
- **Cut out** removes the interval between two clicks.
- **Keys / Shortcuts** selects a supported keyboard profile. These cover CUTROOM's available actions, not every command from another editor.
- **Reset to AI draft** resets the complete manual sequence after confirmation; it is undoable.

In the Together inspector, Start / End select exact times; use **Remove from video** for removal. **Move to start** uses Start as the final position and preserves the selected section's length. In A-only/B-only, **Apply trim** changes clip boundaries and Source in independently.

An empty timeline is valid and stays empty when reopened. Use Original footage to restore a selection, or Undo to continue. Export is unavailable until a source clip or imported media/custom-text occurrence exists on the edit.

### Three-point source placement

1. Optionally select a destination range on the edited timeline first.
2. Open **Original footage**, choose A or B, and drag the source section you want. Choose Together or This source only, then **Place selected footage...**. The source selection is retained instead of resetting to the first five seconds.
3. Choose **Insert (shift source tracks)** or **Overwrite (keep timing)**.
4. Use **At edit position** to place the Source In/Out range at the displayed edit time. Or choose **Selected edit range** to use its captured start and duration. In that mode, Source In remains editable and Source Out is calculated automatically. Switching back restores the manually entered Out and destination.
5. Review the operation and apply. A single Undo reverses it; Redo restores it.

**Insert** retains the existing source insertion behavior. Together shifts A/B and framing, inserts only the chosen source and leaves the other source empty during the new footage. Source-only inserts on that lane. Independent added video/audio, images and titles retain their existing times; this is not a general all-layer ripple command.

**Overwrite** replaces only the destination interval and never ripples or extends the edit. Together removes A/B footage in that interval and sets its layout to the chosen source. Source-only replaces that lane and leaves the other source and layout unchanged. Later clips, added media/audio and custom text stay at the same times, including layers overlapping the replacement. Existing audio routing is retained, so the selected audio source can be silent where Together removes it. Source-linked captions follow the resulting footage; existing corrections on surviving uses are preserved.

The selected edit range is captured when the placement form opens. Its duration determines how much footage is taken after Source In; this never loops, freezes or changes playback speed. Insufficient source footage, extension past the edit end, protected tracks, unsupported tiny surviving fragments and stale source/timeline changes are rejected. Select a shorter range or use Insert where appropriate. Source selections preserve fractional-frame precision in the numeric fields, but browser source preview is not a frame-accurate monitor.

This workflow is an original CUTROOM implementation informed by [Kdenlive's three-point editing documentation](https://docs.kdenlive.org/en/tips_and_tricks/useful_info/insert_overwrite_advanced_timeline_editing.html). No Kdenlive source code is included. It supports CUTROOM's existing A/B scope, not Kdenlive's unlimited track targeting, nested sequences or every editing mode.

## Layout, captions and playback

Select a section and choose a composition in **Layout**: the choice saves immediately. **Entire edit** clears the range so the next choice applies throughout. **Exact range…** exposes numeric scope controls. Source setup (roles, audio, framing and synchronization) remains a whole-edit setting.

When one source is missing, the other fills the frame. If both are missing, the frame is black. Audio follows the explicitly chosen audio source and is silent in its gaps, without silently switching recordings. Captions follow that source's clip mapping. Caption text corrections save separately from timing edits.

When a requested B/split layout has a gap covered by real A picture, Export automatically uses A for that interval. The export dialog and saved export review report the substitution and its duration. Existing B coverage still uses the requested layout. The saved edit and selected audio do not change, so selected B audio remains silent in its gaps. Uncovered A or missing source files still need attention; this fallback is not a guarantee that every project can render.

**Edited video** uses the sequence clock; **Full source** browses original footage without changing the edit. Arrow stepping uses output FPS in the edited sequence and source FPS in Full source. A camera embedded in one file uses crop/layout controls; it is not a recovered separate recording.

## Workspace

On larger screens, drag the video/timeline divider to resize either area; double-click resets it. The video-only **Full screen** includes both sources, captions and transport. Escape returns to editing. The fallback is a video-only overlay if native fullscreen is unavailable.

**How to edit** gives a short five-step guide. Advanced source behavior is collapsed under an optional explanation. AI draft settings are below output settings, so optional model setup does not obstruct everyday editing or export.

## Safety and current boundaries

- Manual sequence actions require the current project revision. A conflict loads the latest version and asks for a new selection rather than replaying a destructive action at stale coordinates.
- A/B are two source tracks, not unlimited layers or a per-clip audio mixer.
- New operations require at least one frame at the selected output FPS. Unsupported tiny leftover fragments are rejected atomically, never silently discarded.
- Sequence length can grow, but each clip must use footage that exists in its recording. Linked edits cannot repair incorrectly synchronized input files.
- Synthetic UI and real 30/60 FPS FFmpeg regressions cover linked edits, gaps, captions and audio. These do not certify transcription accuracy, real user satisfaction, or long/reordered 4K performance.
- Timeline editing, previews and exports remain local. CUTROOM remains free and open source. Optional cloud AI sends audio/transcript context to the provider selected by the user; its quotas and possible charges are separate. See [AI connection choices](AI_CONNECTIONS.md).

### Atomic non-ripple occurrence removal

Every surviving raw row, order, source clock, effect, mixer, asset, original file and explicit sequence duration stays unchanged. This does not delete source files, remove primary A/B footage or retime automatic captions. Even removal of all independent layers keeps the saved duration and remains undoable.

The server requires a valid editor-sequence snapshot and structurally valid, unambiguous layer identities. Removal deliberately does not require ready assets or run move/content normalization: offline or disabled occurrences remain cleanable. Selection clears only on confirmed installed success, and Undo restores occurrences rather than the ephemeral selected set. ## Independent-track editing protection

A saved track can be locked from its real timeline header or its existing Tracks manager row. Selection, Index navigation, source audition, playback and export remain available. Locks protect the saved occurrences (including disabled clips), membership and relative same-kind track ordering, not the final rendered appearance. Rename is still metadata-only; global mix, output and original A/B settings are not frozen. Source A/B retain their separate protection system.

Version 1 is unchanged on read. The first explicit true `layer_track_lock {track_id, locked}` upgrades the model to version 2, whose records require exact `id`, `kind`, `name` and boolean `locked` fields. False on version 1 is a no-op. Unlocking a version-2 project does not silently downgrade it. Old readers that only understand version 1 refuse version 2 rather than ignoring its protection. A normal new version-2 track starts unlocked. Render ordering, inventory and output fingerprints ignore protection-only metadata.

Lock/unlock is a persistent editor preference outside media Undo/Redo: it adds no history step and preserves Redo. Current protection is reapplied by ID when an old history state is restored; historical lock flags are not revived. Undo/Redo that would change protected contents, remove a locked track/model, or cross its prior relative ordering is refused without consuming history. Unlock first to undo such an operation. Once no locks remain, Undo of the original track conversion can still restore exact legacy absence.

Each staged edit and final store save checks protected members, order and referenced original/effect identity. Numeric edits, framing, Trim, Slip, Split, Move, Remove, group edits and any ripple that actually changes protected clips refuse atomically; safe edits elsewhere remain available. A locked empty track cannot be removed, and other tracks cannot cross it. Duplicate may read protected content, but new occurrences use an unlocked compatible destination. Explicit locked destinations refuse; automatic allocation skips them. Asset-keyed Chroma and regenerated stabilization originals used by locked occurrences are also protected, while ordinary proxy/status preparation is allowed. Source-file replacement/removal and rollback preflight these constraints before file moves. B resets retain the independent model/protection under the existing explicit reset policy.

The client rechecks canonical action readiness before preview and after awaited saves, then submits one strict-revision action. Lock changes refresh in place without restarting Program playback, changing the playhead or clearing selection. Protected local text buffers remain available for unlock/retry or local discard; their unsupported overrides do not paint over saved protected content. Shared Chroma candidates likewise remain local and recoverable. Locks are accidental-edit protection, not access control, immutable media storage, a guarantee that composited pixels never change, or a replacement for backups. Whole-project deletion remains its existing separate operation.

Unlocking an already protected track is a local-draft recovery action: it does not apply or discard pending text/media/Chroma changes. Real in-flight saves and gestures still block it.
