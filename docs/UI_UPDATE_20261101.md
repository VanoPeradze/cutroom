# 1.3 UI update — 1 November 2026

This change improves the local editor and the public website without changing the 1.3 version label.

The editor keeps Export visible on narrow screens, gives portrait previews more room, improves recent-project names and touch controls, and keeps the export summary readable. Original-footage preview failures now offer Retry preview, preserve the selection, zoom and cursor, and clear the error when a source loads successfully. Missing-FFmpeg export failures have an actionable bilingual explanation.

The website preserves its existing background motion, adds pause/resume with reduced-motion support, shortens the download introduction, and brings the authentic existing editor screenshot earlier on the page.
