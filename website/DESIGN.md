# CUTROOM / The cutting room

## Surface and direction
This is the public, bilingual CUTROOM marketing and download site at the existing Expo project. Its mode is Persuade, supported by real product evidence and clear installation guidance. The previous charcoal split hero and boxed download panel were explicitly rejected as too similar to the original. This redesign replaces that composition rather than polishing it again.

The site uses a cool-white studio canvas, a large two-line Geist headline, dark green type, mint platform emphasis and the unchanged cyan/violet CUTROOM mark. Hebrew uses the self-hosted Noto Sans Hebrew family. All fonts are from Google Fonts under the SIL Open Font License; their exact license files ship beside them. No external font requests, tracking, framework or animation dependency is added.

## Composition
- A compact, sticky navigation keeps the existing anchors, language choice and visible download action.
- The centered opening gives the product statement room to breathe. Real Windows/Mac download actions sit together, with visible beta qualification limits and a native installation disclosure.
- The original editor capture sits on a restrained offset mint backing. Its date and archival status are explicit. The enlargement always opens the unmodified original.
- Three varied format diagrams introduce the existing starting points without simulating application controls.
- A new workflow section explains source review, sequence editing and export. Its links actually select the matching Media, Edit or Output gallery tab.
- The workspace browser is horizontal at every breakpoint; keyboard and RTL behavior match that orientation.
- AI choices are readable, equal-status alternatives, not a claim that external providers or local models are already configured.
- Installation help, current release evidence, known limitations, privacy and source/license links remain intact.

## Engineering and accessibility
The existing HTML, native CSS and small JavaScript stack remain. Existing tab semantics, image-dialog focus return, native disclosures, hash deep links and mobile navigation are preserved. Motion uses transforms and opacity with IntersectionObserver, has a page toggle and follows reduced-motion preferences. Content remains present without JavaScript. Contrast tests cover the real new surface tokens and both platform buttons.

The design keeps all public route IDs and exact approved download links. A site preview is not app qualification. Current production pins may change only after fresh native release evidence and retained archive hashes are verified. No historical release may be replaced.

## Validation
Structural, behavior and contrast tests: 54 passed, 2 Windows symlink tests skipped. Local page/anchor/asset/Expo/download validation passed. Live Chrome review of the immutable preview passed at 1180px desktop and constrained 768px, 390px and 320px browser viewports, in English and Hebrew/RTL. The mobile menu, language-change focus return, workspace links, gallery keyboard navigation, original-image dialog and Escape focus return were exercised. The browser viewport checks are not a physical-phone or current-app acceptance test. Historical app images remain explicitly dated; new application screenshots were not captured. A final bounded pass tightened the hero spacing, preserved the active download button contrast and stacked small-screen platform actions.
