How do I install it?

WINDOWS + MAC · 1.1 BETA

The ZIP has exactly two folders: windows and mac. Each has a launcher, START HERE.html for help, and App for technical files. Extract everything and keep them together; dependencies and AI models are not bundled.

Windows: Double-click START CUTROOM.bat in windows. Setup downloads missing dependencies; keep the launch window open.

Mac: macOS 15+, Apple Silicon or Intel. Open START CUTROOM.command in mac. It needs Python 3.11/3.12 and FFmpeg 7; setup uses existing Homebrew with your approval. This is not a signed Mac app. Local transcription uses the CPU. Finder, Safari and real-footage performance still need manual testing.

Linux: source only, with no packaged download or verified native Linux QA. It needs Python 3.11/3.12, venv/pip and FFmpeg/FFprobe with subtitle support. Follow the scripts in the platform guide.

Do I need AI or an API key?

No. Manual editing and export need no AI models or account. Optional local AI needs model downloads; Story AI also uses Ollama.

You can connect a compatible cloud provider with your own key. Audio and transcripts are sent after your choice and consent; provider quotas and charges apply.

AI setup and privacy
Where does my footage go?

This website does not accept recordings. Editing, preview and export run on your computer. Sharing with a cloud AI provider is a separate choice requiring consent.
