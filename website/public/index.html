What’s new in the 1.3 beta?

1.3 Beta · Studio and source editing update

8 November: source In/Out marks carry directly into Add source footage. Choose Insert or Overwrite, with optional placement into a captured timeline range. Overwrite preserves sequence duration, respects locked scopes, and supports Undo and Redo.

The editor has a refreshed visual hierarchy, clearer workspace navigation, organized controls and more readable panels. Gallery images still show the earlier interface and retain their original dates.

Stability update, 6 November: if FFprobe is missing or unavailable, import explains how to repair and retry. A failed replacement preserves your saved media and edits.

New video layers include their source sound by default when the file has audio. Select a layer in Media to include or exclude sound, adjust clip volume and fades, or mute it. Saved silent overlays stay silent until you turn their sound on.

The AI draft notice is compact and expandable, with space reserved outside the preview. It still flags a draft shorter than requested; open it for the actual duration, target and explanation.

Picture speed changes the video only. Layer sound plays at normal speed from Source in. Review the preview and export before publishing.

Project setup is clearer on narrow screens, unavailable controls are easier to recognize, and reset messages describe the selected action.

Timeline zoom stays focused on the selection during playback, and thumbnails update more reliably.

What still needs review?

Public beta. Automated checks do not replace a test on your computer. Transcription and AI, physical-device installation, Finder/Gatekeeper/Safari and representative English/Hebrew editing and listening still need manual acceptance. AI drafts may miss context or have weak endings.

With two recordings, confirm that both sources show the same moment before relying on synchronization. A camera appears only where its track covers the edit; an empty B track does not create camera footage.

WINDOWS + MAC · 1.3 BETA

Choose the ZIP for your computer and extract it. Keep the launcher, START HERE.html and App together. Runtimes and AI models are not bundled.

Windows: Install WinGet and Microsoft Visual C++ x64 runtime first. Double-click START CUTROOM.bat beside App. Setup downloads Python and media dependencies; keep the launch window open. The required Visual C++ runtime is not installed by the launcher.

Microsoft Visual C++ x64 - official download

Mac: macOS 15+, Apple Silicon or Intel. Extract the combined ZIP, open its mac folder and run START CUTROOM.command beside App. It needs Python 3.12 and FFmpeg 7; setup uses existing Homebrew with your approval. This is not a signed Mac app. Local transcription uses the CPU. Manual Finder, Gatekeeper and Safari checks remain pending.

Linux: source only, with no packaged download or verified native Linux QA. It needs Python 3.12, venv/pip and FFmpeg/FFprobe with subtitle support. Follow the platform guide.

The optional combined ZIP has exactly two folders: windows and mac. Open your platform folder first.

AI is your choice

Manual editing and export need no AI models or account. Local AI needs separate downloads; a selected speech model that is missing may download on first use. Story AI also uses Ollama. After opening the editor, choose AI connection, On my computer, then Get Ollama to install it separately.

Accessibility help

Use Tab and Shift+Tab to move between controls. Enter follows links; Enter or Space activates buttons and help sections. The first link skips directly to the content.

In the workspace tabs, use the arrow keys, Home and End. In the enlarged screenshot, Escape closes the dialog and returns focus to its opening button.

Use your browser zoom to enlarge the content. The page adapts to narrow screens and respects system preferences for reduced motion and forced colors. Workspace content is also available without JavaScript.

This help applies to this website; the downloaded editor and installation have separate checks. If you encounter an accessibility barrier, report it on GitHub with the page URL, browser and steps. Do not include personal information.
