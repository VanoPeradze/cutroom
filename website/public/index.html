Start on your platform.

Windows and Mac share a ZIP with separate launchers. Linux uses the source checkout and development scripts. Start with a manual edit of a short recording; no AI models or API key needed.

WindowsDownload, extract & launchBeta ZIP

Download the ZIP, extract everything, open windows and double-click START CUTROOM.bat. Keep App and START HERE.html beside the launcher. Keep the launch window open while editing.

First setup needs internet: it reuses Python 3.11/3.12 or downloads a private Python runtime, installs Python packages, and reuses FFmpeg/FFprobe or attempts installation through winget. If FFmpeg is missing and winget is unavailable, the PC owner needs to install the tools. Windows files are unchanged in the Mac update; automated checks do not prove a clean installation on every PC.

Platform requirements and setup
MacmacOS 15+ · Apple Silicon & IntelUnsigned beta

Extract the ZIP, open mac and double-click START CUTROOM.command. Keep App and START HERE.html beside the launcher. It needs Python 3.11/3.12 and compatible FFmpeg with subtitle support; setup offers Python 3.12 and ffmpeg@7 through existing Homebrew with your approval. If Homebrew is missing, start with the guide in the mac folder. Keep the Terminal window open. Local transcription uses the CPU.

This is a source launcher, not a signed Mac app. Automated checks on both architectures do not replace manual Finder/Gatekeeper launch, Safari testing, or transcription and performance checks with real footage. Use the guide if macOS blocks the launcher.

Mac setup and validation details
LinuxSource checkout & development scriptsNative QA unverified

There is no packaged Linux download in the ZIP. This path is for users comfortable running source code. Install Git, Bash, Python 3.11 or 3.12 with venv and pip, plus FFmpeg and FFprobe using your distribution's package manager. FFmpeg needs libass subtitle support, libx264 and AAC, and the command options used by the editor; newer versions are not automatically compatible. Then run:

git clone https://github.com/VanoPeradze/cutroom.git
cd cutroom
chmod +x setup_linux.sh run_linux.sh
bash setup_linux.sh
bash run_linux.sh

setup_linux.sh creates .venv and downloads Python packages; first setup needs internet. chmod is needed because run_linux.sh calls ./setup_linux.sh if the runtime is missing or needs repair. Keep the Terminal window open. These scripts exist in the repository, but native Linux installation and operation remain unverified.

Linux requirements and limitations

After setup, start with a short recording you know well. The steps below describe the Windows/Mac ZIP; on Linux, replace the first two setup steps with the scripts above.

  1. 01

    Download & extract

    Download the ZIP and extract the entire archive into a folder. Don't run files from inside the ZIP. The source package is small; first setup downloads additional components.

  2. 02

    Choose your folder

    Windows: open the windows folder. Double-click START CUTROOM.bat. Mac: open the mac folder and double-click START CUTROOM.command. Follow the prompts and review dependency installation before confirming. Keep the launch window open.

  3. 03

    Add footage. Choose a path.

    Choose Edit it yourself, add a recording and select Open manual editor. Want an AI draft? Choose Short / Reel or YouTube, prepare your AI connection, set the spoken language and check your sources.

  4. 04

    Cut and move clips on the timeline. Use Layout and Captions as needed. Choose your format in Output, open Export and select Start export. Download the result and watch it outside the editor too.

The ZIP has exactly two folders: windows and mac. Each has one launcher, START HERE.html for help, and App for technical files. Keep them together. First setup needs internet. No Codex needed; the editor interface is in English.

A LITTLE MORE DIRECTION

A few things worth knowing.

Setup, models, editing controls and privacy — the useful details before your first session.

How do I download and prepare local models?

Open AI connection, choose On my computer and use Refresh status. A transcription model turns speech into text; a Story model helps plan the edit. You don't need every model.

If the Story engine is missing, install Ollama using the official link in the app, then refresh the status. Transcription models do not require Ollama.

Choose a model, review the download estimate and confirm. Progress and cancellation appear in the same panel. Downloading does not change the project's quality profile: match it to the model you downloaded and save your Local AI choice.

AI Story Shorts need transcription and a Story model. Standard chronological YouTube cleanup can use transcription without Story. A downloaded model does not guarantee that your computer has enough memory to run it.

How much space do I need? Which models?

The ZIP size is not the installed size. Setup downloads processing dependencies, and local AI adds model downloads. Source footage, added media, previews and exports need additional disk space.

How do I connect cloud AI? Is it really free?

Open AI connection and choose Online — Free tier for Groq, or My own API account to choose Groq or a compatible provider. Enter your own API key, check the destination and content-sharing notice, and consent. Then select Use this cloud connection.

Open the official Groq key page

CUTROOM does not charge you. Free accounts have quotas; paid accounts can incur charges. Selecting Free tier in the app does not change your provider plan or cap a paid account's charges. Check your account with the provider.

A compatible provider must expose /chat/completions with JSON-object responses and /audio/transcriptions with verbose_json and word timestamps, at the same public HTTPS base URL. Enter that provider's model IDs. A chat subscription is not an API key; a chat-only service is not enough. Local and private-network addresses are not supported by this connection.

The speech model returns words and timing. The Story model reads the transcript and returns an edit plan; it cannot recover missed speech. The current connection uses the same provider, base URL and key for both capabilities. Check both with a short recording.

Entered keys stay in memory for the running session. Changing provider or endpoint requires a fresh key and consent. A Story task may make several requests. Check provider limits and result quality with a short recording before a long project.

What stays on my computer? What goes online?

This website is a presentation and download page. It does not accept footage for editing or ask for an API key. Enter your key only in the downloaded app.

Manual editing and local AI processing do not send content to a cloud AI provider. Cloud mode sends the selected audio, transcript and editing instructions to your chosen provider, not video frames. Use only content you are allowed to share. The provider's data policies apply.

Do I need NVIDIA? Can I work offline?

An NVIDIA card is not required. CPU processing is available, but larger models can be slow or need more memory than you have. Performance and compatibility are not guaranteed on every computer.

Once the required dependencies and models are downloaded, editing and cached local models can work offline. Cloud AI requires an internet connection.

How do I arrange camera and screen recordings?

With two files, assign the screen, camera and audio source. Check synchronization before editing. If your camera is embedded in one file, define its region and inspect the crop. Automatic detection is not perfect.

In Layout, choose screen only, camera only, Stacked, Side by side or Picture in picture. Set whether your change applies to the entire edit or a specific section. Use Clip framing to adjust position and zoom by section.

How do I cut, move and restore clips?

Select / Move selects and repositions a clip. Range marks a section to remove. Cut splits a clip at the chosen position. After splitting, move the parts individually; clip edges trim or reveal more of the original recording.

Edit target chooses A and B together or a single source. Open Original footage to inspect the source and restore removed sections. Use Undo or Redo when needed.

How to edit inside the editor explains the tools. Under Keys / Shortcuts, choose a preset and review its supported actions. Shortcuts stay inactive while you type in a field.

How do I add media, mix audio and change speed?

In Media & audio, select Add media, wait for preparation and add the file at the yellow playhead. Add video, images, music or voiceover, move and trim them in the timeline, and adjust volume and fades. These layers fit inside the current edit duration; they do not extend it automatically.

Audio mixer balances original sound, voiceover, music, effects and master level. Mute also affects export; Solo is preview-only. No AI or API is needed. Check the exported mix too.

Picture speed on A/B clips changes only the picture, keeping clip length and speech timing. It can lose lip sync or hold the last frame when the source ends. It does not speed up the whole picture-and-sound edit.

How do I add text and captions without AI?

Open Captions and add your own text with a start and end time. Create titles, labels or captions, style them and check their timing in the preview. No automatic transcription, model download or AI account is required.

Already have subtitles? Import an SRT or VTT file and check its timings against your edit. Correct the text and timing before export. This uses the text you provide; it does not automatically transcribe or translate.

How do I find and manage saved projects?

Open Projects to search by name, sort, reopen or rename a project. You can also reopen and rename projects from the recent-project list on the welcome screen.

Deletion asks for confirmation. It removes the project and its media copies, edits, previews and exports stored by CUTROOM. Your original files outside CUTROOM stay where they are.

Can I correct Hebrew transcripts or translate?

Select Hebrew as the spoken language and use the Hebrew-focused local model if appropriate. Results depend on the model, recording quality, noise and speakers. Equal accuracy across languages is not guaranteed.

Local Balanced or Quality can recheck up to two weak units, at most 30 seconds each and 48 seconds of audio per local pass, using the loaded model. Timing, confidence and English-term checks determine whether to keep the original. Lite adds no such retry. Existing model-upgrade paths are separate; this is not a processing-time limit. No measured accuracy improvement or perfect language detection is claimed.

Review and correct the transcript before export. In Captions, style subtitles, burn them into your video or export SRT. Transcription is not translation; CUTROOM does not promise an automatic translation service here.

Which formats and frame rates can I export?

In Output, choose an aspect ratio such as 9:16, 16:9, 1:1, 4:5 or Source. Export at 720p, 1080p, QHD 1440p or 4K 2160p, with 24, 25, 30, 50 or 60 FPS. MP4 rendering stays local; higher resolution uses more resources and does not recover missing source detail.

Exporting at 60 FPS does not create new motion detail in lower-frame-rate footage. Check framing, captions and audio in the exported file before publishing it.

What if processing fails or I don't like the result?

Cancel an active process and switch to manual editing if needed. Originals remain unchanged. Read the error: missing connections, missing models, quotas and limited computer resources need different fixes. Never include API keys in screenshots or reports.

Cancellation cannot undo usage already accepted by a cloud provider. Before rebuilding a draft, review the warning about your manual changes. For beta testing, work with copies of your footage.

What does free and open source mean? How do I give feedback?

Source code is public on GitHub and included in the download under the MIT License. Explore it, modify it or contribute improvements. There is no CUTROOM subscription or CUTROOM watermark. Third-party tools and models have their own licenses. Optional AI services follow their provider's pricing.

This is a beta, not a promise of a perfect edit in one click. To report a problem, describe what you tried, what happened and the error message. GitHub reports are public: leave out private client footage, keys and personal information.
