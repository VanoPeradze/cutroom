Install on Windows, Mac or Linux

CUTROOM uses Python 3.12. If it isn't installed, Windows setup downloads a private copy into the CUTROOM folder.

WINDOWS + MAC · 1.1 BETA

Choose the ZIP for your computer and extract it. Keep the launcher, START HERE.html and App together. Runtimes and AI models are not bundled.

Windows: Double-click START CUTROOM.bat beside App. Setup downloads missing dependencies; keep the launch window open.

Mac: macOS 15+, Apple Silicon or Intel. Open START CUTROOM.command beside App. It needs Python 3.12 and FFmpeg 7; setup uses existing Homebrew with your approval. This is not a signed Mac app. Local transcription uses the CPU. The beta guide lists the remaining Finder, Gatekeeper and Safari checks.

Linux: source only, with no packaged download or verified native Linux QA. It needs Python 3.12, venv/pip and FFmpeg/FFprobe with subtitle support. Follow the platform guide.

The compatible combined ZIP still has exactly two folders: windows and mac. Open your platform folder first.
